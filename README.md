# Truegauge Launchpad

IBuild a modern, professional marketing website for "Truegauge AI", a South African AI automation and workflow implementation consultancy. Design should feel trustworthy, clean, and premium — use a teal/dark green and white/charcoal color palette (gauge/instrument theme), with subtle geometric or dial/gauge-inspired accents. Avoid generic "AI hype" visuals like neon or glowing brains.
